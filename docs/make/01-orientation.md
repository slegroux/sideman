# 1. Orientation: tempo, key, and what's in the Set

**You'll have:** a fresh Set at 122 BPM in F minor, and a habit — asking
Claude what exists before asking it to change anything.

## Say

> Set the tempo to 122 and the key to F minor. Then tell me what's in this
> Set.

## What Claude does

It writes the tempo and the key straight into the Set, then reads the Set
back and describes it: the tracks, the scenes, the return tracks, the master.
A new Set has two MIDI tracks, two audio tracks, eight scenes, two returns.

## What you'll see in Live

The tempo display reads **122.00**. In the Clip View's Scale section, once
you have a clip, the key is F Minor. Nothing else changes yet.

## Check

Ask: *"what's the tempo, and how many tracks are there?"* — you should hear
122 and 4. If Claude ever answers a question like this without a pause, be
suspicious: the pause is it asking Live.

::: {.callout-note}
## Why Claude asks instead of guessing
Claude doesn't know your Set. Everything it says about it comes from reading
Live at that moment, and everything it changes is one write to one named
thing. That is also why it can tell you exactly what it did.
:::
