# Learn

Sideman is an Ableton Live MCP server: you describe what you want, Claude
does it in your Set, and you can always check. Two ways in:

- **[Start here](make/00-start-here.html)** — three prompts, ten minutes, a
  loop from nothing, automation as a curve, and Claude noticing what you did
  by hand.
- **[The tutorial](tutorial.html)** — the same loop driven from a Python
  notebook, for readers who want to see the calls.

The full course — *Make a track with Claude*, ten lessons that build a
melodic house track from an empty Set, and *Under the hood*, the same
lessons as executed notebooks — is a separate publication.
