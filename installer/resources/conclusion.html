Almost done — two steps.

1. Turn it on in Live. If Ableton Live was open, quit and reopen it (Live only looks for new scripts when it starts). Then:

Settings (or Preferences) → Link, Tempo & MIDI → Control Surface → pick AbletonLOM in any empty slot.

AbletonLOM is the name of the script inside Sideman. There is no entry called “Sideman” in that list.

2. Restart Claude. Quit your Claude session and start a new one, then ask it:

What's in my Set?

If Claude says it has no Ableton tools, it was not registered automatically — the claude command was not found on this Mac. Install Claude Code, then run this once in Terminal:

claude mcp add --scope user sideman -- \
  "$HOME/Library/Application Support/Sideman/python/bin/python3" -m mcp_server.server

If macOS refused to open this installer at all and you had to hunt for it: Sideman is not signed yet. Open it once, then go to System Settings → Privacy & Security and click Open Anyway.

If a file called CONFLICT.txt has appeared in ~/Library/Application Support/Sideman/, something you already had was in one of the places Sideman needed — it was left untouched, so step 1 above still has to be done by hand. Open that file; it says exactly what to do.

To remove Sideman later, run ~/Library/Application\ Support/Sideman/uninstall.sh
