This installs Sideman, which lets Claude control Ableton Live — build a drum pattern, rename tracks, load a device, write automation, all by asking.

Everything goes in your own home folder. No password needed, nothing is installed for other users, and it includes its own private copy of Python so you do not need to install anything else.

There is one thing left to do by hand afterwards. The last screen tells you what it is — please read it.
